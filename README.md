# בונה מערכי שיעור באזרחות

פלטפורמה ייעודית (React + TypeScript + Vite, client-side בלבד, ללא שרת) לבניית מערכי שיעור באזרחות, המבוססת על 4 עקרונות:

1. **שיטת ניתוח אירוע בת 4 שלבים** (זיהוי מושג → הגדרה → ציטוט → קישור מפורש) המוטמעת בכל פרומפט שנוצר.
2. **התאמה אמיתית לשונות** — תוכן נפרד ומלא לכיתה עיונית ולכיתה מתקשה, לא רק הערות.
3. **פתיחה באירוע אקטואלי** עם שאלות מנחות רגשיות ומשפטיות.
4. **ללא backend וללא עלות API נוספת** — האתר בונה פרומפט מובנה, המורה מדביק אותו ב-Claude.ai (המנוי שכבר יש לו), ומדביק את התשובה בחזרה לפירוק אוטומטי לשדות.

## זרימת עבודה

1. בחירת נושא מתוך מאגר 10 נושאי אזרחות (או נושא מותאם אישית).
2. הזנת מטרות/מיומנויות והדבקת/העלאת חומרי גלם (טקסט, PDF, Word, קישור).
3. העתקת הפרומפט המוכן והדבקתו בשיחה עם Claude.
4. הדבקת תשובת ה-AI ופירוק אוטומטי לשדות מובנים לפי כותרות markdown קבועות.
5. עריכה ידנית, שמירה לספרייה אישית (localStorage), תצוגת הדפסה נקייה וייצוא ל-Word.

## פיתוח

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה לפרודקשן
```
